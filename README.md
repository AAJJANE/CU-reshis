# Решись Авиа — прогноз продаж билетов

Веб-приложение (вариант C): страница с формой отправляет данные через JavaScript на backend на Python (Flask),
backend считает прогноз по файлу с прогнозом спроса из ML-части и возвращает результат.

## Что умеет

- **Простой прогноз.** Пользователь выбирает пункт отправления, пункт назначения, дату вылета и цену билета.
  Приложение показывает число мест и прогноз продаж:

  ```
  желают = 0.5_base_demand − price_sensitivity × (цена − base_price)
  купят  = min(seats, max(0, желают))
  ```

- **График распределения спроса** при введённой цене: 9 сценариев прогноза (квантили 0.1–0.9),
  медиана выделена и совпадает с числом «желают», красная линия — число мест в самолёте.

- **Регистрация и авторизация.** Прогноз доступен только после входа. Логин и хэш пароля
  хранятся в базе SQLite (`data/users.db`), сами пароли не хранятся. Вход запоминается в сессии Flask,
  cookie сессии подписывается секретным ключом. Без входа главная страница перенаправляет
  на страницу входа, а API отвечает кодом 401.

## Структура проекта

| Файл | Что делает |
|---|---|
| `app.py` | Flask-приложение: страницы регистрации и входа, главная страница, API `POST /api/forecast` |
| `forecast.py` | Загрузка данных и расчёт прогноза по формуле |
| `auth.py` | Пользователи: база SQLite, регистрация, проверка пароля |
| `templates/base.html` | Общий шаблон страниц (шапка, имя пользователя, «Выйти») |
| `templates/login.html`, `templates/register.html` | Страницы входа и регистрации |
| `templates/index.html` | Страница с формой прогноза |
| `static/app.js` | Отправка формы через `fetch`, вывод результата и графика |
| `static/style.css` | Оформление |
| `static/chart.umd.js` | Библиотека Chart.js для графика |
| `data/Arshinova_Evgeniya_Aleksandrovna_my_forecast.csv` | Мой прогноз спроса из ML-части (результат задания 7) |
| `data/routes.csv` | Параметры маршрутов: базовая цена, чувствительность к цене |

Открыть в браузере: http://127.0.0.1:5000, зарегистрироваться и войти.
База пользователей и секретный ключ создаются автоматически при первом запуске.

## API

`POST /api/forecast`, тело запроса (JSON):

```json
{"origin": "Москва", "destination": "Сочи", "date": "2026-06-12", "price": 10000}
```

Ответ: число мест `seats`, спрос `wants`, продажи `buys`, базовая и рекомендованная цена,
9 сценариев `scenarios` для графика. При неверных данных — код 400 и текст ошибки в поле `error`.
