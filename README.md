# Решись Авиа — прогноз продаж билетов

Веб-приложение (вариант C): страница с формой отправляет данные через JavaScript на backend на Python (Flask),
backend считает прогноз по файлу с прогнозом спроса из ML-части и возвращает результат.

## Что умеет

- **Простой прогноз.** Пользователь выбирает пункт отправления, пункт назначения, дату вылета и цену билета.
  Приложение показывает число мест и прогноз продаж:

  ```
  желают = 0.5_base_demand − price_sensitivity × (цена − base_price)
  купят  = min(seats, max(0, желают))
  ```

- **График распределения спроса** при введённой цене: 9 сценариев прогноза (квантили 0.1–0.9),
  медиана выделена и совпадает с числом «желают», красная линия — число мест в самолёте.

## API

`POST /api/forecast`, тело запроса (JSON):

```json
{"origin": "Москва", "destination": "Сочи", "date": "2026-06-12", "price": 10000}
```

Ответ: число мест `seats`, спрос `wants`, продажи `buys`, базовая и рекомендованная цена,
9 сценариев `scenarios` для графика. При неверных данных — код 400 и текст ошибки в поле `error`.
